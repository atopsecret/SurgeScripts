# 菜鸟取件小组件 1.3.1 验证记录

日期：2026-11-09。

**1.3.1 正在发布。手机实际连接尚未验收。** 本版修复真实 RPC 已出现、却因未观察到此前 UID 签发而不能建立会话的本地限制。iOS 官方查询端点已由本人手机实测确认；实际正文兼容、独立摘要查询与关闭 App 后的新查询仍分别验收。

## 实质改动

- 精确 HTTPS RPC 的合法实际 token 和业务模板可直接建立 bearer 候选，不再要求先重新签发。按 token 摘要隔离凭据会话，不冒充已核实账号 UID。
- 新 token 使用全新代次，清空旧摘要、确认和成功次数。32 项撤销摘要同时约束会话与隔离屏障；容量满时停止，不淘汰旧 token 放回旧流量。
- 先保存并回读屏障，再保存候选。首次候选保存失败、B 保存失败、在途 A 查询、迟到签发响应和旧 H5 捕获都不能撤销已保存的新屏障。
- HTTP hook 不发送个人查询；读体一次并原字节透传。主组件发送带新时间戳的独立 POST，成功模型和本机写回均通过才确认摘要。
- 未知正文保存固定字段类型、缺项与额外数量，不保存 token 值、未知字段名、包裹正文或任意异常原文。没有已接受模板时不猜 iOS 参数。
- 合法 1.3.0 官方、H5、响应观察、App 观察和发送对照保留原代次、窗口与失败状态，不因升级恢复终止候选或重跑发送对照。
- 沿用同一模块、七入口和五个精确 MITM 主机，不更改证书、代理、权限或账号。

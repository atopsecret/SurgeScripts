# 菜鸟取件小组件 1.3.0 验证记录

日期：2026-11-09。

**1.3.0 的实际取数代码和离线回归已完成，普通发布与原地址回读进行中。手机实际连接尚未验收。** 本版新增官方专用 token 与独立摘要 POST，不把发布、测试通过或 Android 静态证据当作 iPhone 接通。

## 本次实质实现

- 精确采集官方 `mtop.cainiao.guoguo.widget.token.get.cn/1.0` 的成功响应，与同次一致的账号摘要及签发票据绑定。显式版本冲突拒绝；公共时间、SID、Cookie 和任意 SUCCESS 不作专用 token。
- 只在实际出现固定 `WidgetLogisticsService/1.0.0/queryWidgetDetailsV2` 请求，且 token 与签发结果完全相同后保存受限业务模板。源、渠道、品牌、安装状态和授权版本来自该次实际请求，不在 iPhone 硬填 Android 值。不保存或发送位置。
- 主组件发送自己的新 POST，每次使用新递增毫秒时间戳，保留 TLS 校验、禁止重定向及十八秒总预算。不附带 App Cookie、SID、原生签名或 H5 sign；不缓存 App 的包裹响应来冒充刷新。
- 结果只确认官方待取摘要。数量使用 `agentSignPackNum`，摘要只显示数值 `logisticsStatus=900`；正计数而无摘要时如实提示。不声明完整个人列表、分页查全或结构化取件码，不从描述数字猜码。锁屏默认隐藏整个取件摘要。
- 新官方状态存在时，旧 H5 请求／响应候选只观察，不再改账号屏障；旧 H5 在途任务同样停止。换号、冲突、退出、失效、未知参数、存储失败和迟到结果不会恢复旧账号查询。`off` 只清本组件键。
- 仍为一个在线模块、同一份自包含 JS。七个入口、五个精确 MITM 主机；三个响应入口互不重叠。不要求电脑、HAR、APK、复制凭据或另装诊断。

## 独立查询验证的范围

实际自包含脚本的默认入口已经用合成数据完成：

1. 真实形状的签发请求票据及 token 响应，原字节透传。
2. 同 token 的实际 RPC 参数采集，丢弃可选定位，不带出 App Cookie 或一次性签名。
3. 第一次新 POST 成功，记录官方摘要。
4. 不再调用任何 App 捕获入口，第二次 generic 仍发送新 POST 与新时间戳，取得新的合成摘要。
5. B 保存失败后的具体账号屏障不被旧 A 的请求或 Cookie 响应撤销；本人 B 的新签发与模板仍可恢复。
6. 专用 token 被拒绝后停止；重复同值捕获不复活。没有模板、未知结构或超限正文不猜测补齐。

这是**离线独立请求实现验证**，不是对真实服务器或 iPhone 的成功声明。

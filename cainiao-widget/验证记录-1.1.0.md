# 菜鸟取件小组件 1.1.0 验证与发布记录

日期：2026-11-08。环境：macOS arm64、Node.js 26.5.0、Python 3.14.3。

本轮实现手机查件页登录态捕获，替代默认电脑扫码流程。只进行了公开文档读取、合成凭据离线测试及本地排版检查，没有登录用户账号，没有请求真实个人包裹，没有修改手机 CA 或系统设置。

- 全仓 JavaScript：**555/555 → 594/594**，失败、跳过均为零。
- 公共静态回归：**35/35 → 38/38**。

## 本轮覆盖

1. 两个精确 HTTPS H5 网关与数字版本匹配；拒绝伪域、非 443 端口、userinfo、原生 `/gw/` 通道、未知版本和路径后缀。
2. 只读原生请求头、多头 Cookie 冲突检测、正文不消费、请求不重建、捕获不发网络请求。
3. 账号标识与会话 Cookie 组合只作为候选；匿名请求和访客网关 token 不覆盖已有登录态，完整个人列表成功才确认连接。
4. 自动凭据优先、手动备用与明确的 `manual/off`；自身后台标记忽略、网关 token 轮换和新手机 Cookie 优先。
5. 账号切换先保存隔离屏障，凭据写入抛错或静默失败后仍阻断旧账号；手动空参数不清屏障，自动模式读屏障失败不发查询。
6. 查询、分页及读体途中新的账号或 token 停止旧任务；每次刷新独立 `runId`，较早成功/失败不回滚新快照；关闭后旧任务不恢复已清状态。
7. 自动模式响应 Cookie 继续使用必要凭据白名单，昵称与追踪 Cookie 不落地；只读诊断区分候选、连接及账号阻断，不显示凭据或账号摘要。
8. 过期/验证会话保留同账号历史结果并等待新手机捕获；继承分页完整性、总预算、七天缓存、包裹去重和锁屏隐私回归。

独立只读复核发现三项问题：新账号写失败后可能恢复旧账号查询、同账号并发失败回滚新结果、网关响应无关 Cookie 落地。上述问题及两个账号屏障旁路已修复，合成探针与回归通过。

## 外观

保留浅深色、桌面四种尺寸与锁屏三种尺寸。新增手机首次连接、关闭连接和本机存储异常提示；点击统一使用官方手机查件页。

49 个样例包含 `160×160` 小号、`292×141` 最小中号、常用中号、长站名、超长码、缺码、旧结果和锁屏隐私。预览由实际 DSL 近似渲染；已目视检查新接入、最小中号及状态概览，不将其称为 Egern 真机截图。

## 官方协议依据

- [Egern JavaScript API](https://egernapp.com/zh-CN/docs/javascript-api/)：Request 不返回即透传；Headers 支持大小写无关 `getAll()`；JSON 存储 API 同步。
- [Egern 脚本配置](https://egernapp.com/zh-CN/docs/configuration/scriptings/)：原生 `http_request`、`body_required: false`、`generic` 和超时字段。
- [菜鸟官方手机查件页](https://page.cainiao.com/guoguo/app-myexpress-taobao/)及其[官方 bundle](https://cn.alicdn.com/guoguo/app-myexpress-taobao/0.0.8/index.js)：页面配置 MTOP `prefix=acs`、`subDomain=m`，SDK 默认生产网关 `h5api.m.taobao.com`。

网页 SDK 在淘宝内可能走 WindVane 原生桥，不保证每次打开页面均产生可复用的 H5 Cookie。请求头没有 Domain/Path 元数据，两个固定网关间仅作待验证候选，不伪称浏览器作用域已完整重建。

# Apple 天气增强：Egern 原生转换

## 输入与范围

- 用户指定来源：`https://kelee.one/Tool/Loon/Lpx/AppleWeatherEnhancer.lpx`。
- 现场直连与网页提取均失败；直连为 Cloudflare HTTP 403，不能声称核实了该地址当前内容。
- 采用公开镜像 `Moli-X/Tool` 的 `X` 分支，文件标注日期为 `2026-10-02 13:57:49`，引用 `NSRingo/WeatherKit v3.1.0`。
- 保留两条响应脚本、三个拒绝域名条件、Apple ASN 714/6185 的 QUIC 条件和唯一 MITM 主机。
- 不擅自升级到 WeatherKit 3.3.x，不新增请求改写，不修改用户设备配置。

## 实现

1. 使用 Egern 原生 YAML、`env_schema` 参数界面和 `export default` 异步入口。
2. 复用 Apache-2.0 的 WeatherKit v3.1.0 算法、数据集和 FlatBuffers 编解码。原生 `ctx.http`、`ctx.storage` 替代旧客户端全局 API，不运行兼容壳，不使用 `eval`。
3. 上游 `src/proto` 子模块不可公开读取。使用 `wuchunkei/weather-kit` 公开保存的、从相同 v3.1.0 发布包还原的 `wk2.js`，固定提交和哈希；通过二进制样例与原发布脚本对照验证。
4. 构建把每次调用的核心放入独立闭包，HTTP、设置、缓存及日志不通过可变全局上下文共享。
5. 保留默认中国大陆天气替换、下一小时降水补充和 AQI 算法。彩云默认公开备用令牌沿用上游，不包含用户凭据；外部数据可用性仍取决于上游服务与用户 API 权限。
6. 旧 `Storage` 不再提供 BoxJs 选项。配置只读取 `ctx.env`；缓存使用独立 Egern 键，不能与 Loon/Surge 自动共享。
7. Egern 官方文档列出 `REJECT`，因此使用 `REJECT`，不宣称与 Loon `REJECT-DROP` 的丢包方式相同。`protocol` 使用文档化小写 `quic`。

## 错误与边界

- 只处理精确 WeatherKit 主机、可用性 JSON 和天气 FlatBuffers；非成功状态、非目标、未知媒体类型不消费正文。
- 消费过的正文必须显式回传。解析、API、编码失败时返回保存的原始正文，不返回已被消费的流。
- 外部 API 仅使用 HTTPS，受请求次数及超时限制；不向日志、诊断存储写入位置、完整 URL、请求头或 API 令牌。
- 沿用上游已知 FlatBuffers 模型；不承诺保存未来 Apple 新增而模型尚未识别的字段。
- 不对 Egern 真机导入、CA 信任或 Apple 天气页面效果作未经实测的承诺。

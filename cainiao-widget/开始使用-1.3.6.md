# 菜鸟取件小组件 1.3.6 手机接入

**1.3.6 正在发布。手机实际连接尚未验收。** 手机已确定实际 RPC 被拒绝在 TIMESTAMP，类型为 number；未读取值，小数仅为推断。本版只允许该输入为有限正数至 `Number.MAX_SAFE_INTEGER`（含小数），只验证、不保存或复用。独立新 POST、本机时间和状态仍使用正整数毫秒，其它合同与屏障不变。

1. 更新原模块及其 JS，确认模块描述、generic 和查询 hook 的 JS 首行均为 **1.3.6**。保持 `CONNECTION_MODE=auto`、手动 Cookie 留空，不重复添加模块。
2. 保留已有**菜鸟 App 自带的小组件**，等它下一次真实刷新；没有时才添加并正常打开本人菜鸟 App 一次。不删除重装、不退出重登、不导 HAR。
3. 回到 Egern 运行**“菜鸟取件”**。实际 token 和模板被接受后才发新的独立 POST；原“菜鸟连接状态”可查看本轮阶段和固定拒绝类别。
4. 首次独立摘要成功后关闭菜鸟 App，再运行一次。第二次新请求也成功才确认独立查询，升级本身不代表接通。

## 覆盖范围

签名与 UTF-8 的独立校验、原始 JSON 签名、网关 token 引导与重试、Cookie 域和路径及过期处理、失败返回码、分页完整性、总预算、账号缓存隔离、旧结果保留、真实码及哨兵过滤、驿站代收、重复包裹与缺主键处理。

复核发现并修复的三项边界：没有导入 `unb` 时也要跟踪服务器补出的身份；读体完成后仍要检查时间预算；没有可靠标识时不能把同站多个缺码件合成一件。附加探针确认翻页中身份变化或删除不会回显旧快照或本轮部分结果。

登录助手覆盖 HTTPS 域边界、逐跳重定向、标准 CookieJar 的域路径与过期选择、扫码 POST 表单、未知状态和终态、硬总时限、COUNT 的精确成功码及混合失败拒绝、只在成功后导出、文件 `0600` 与拒绝覆盖。

## 外观

**45 个同源 DSL 合成预览**通过组件外框、父容器与取件码裁切检查。包含浅深色、四种桌面和三种锁屏、空数据、首次连接、过期/断网缓存、验证、分页部分结果、缺码、长站名与超长码。

覆盖最小中号 `292×141`、常用中号 `338×158`、小号 `160×160`、锁屏圆形 `60×60`。目视检查取件码与站名的层级、长文本和旧数据提示。原生卡片使用末尾 spacer，预览没有靠无条件 CSS stretch 模拟全部排版。

发布预览在 [浅深色与锁屏](preview/overview.png) 和 [状态与边界](preview/states-overview.png)。预览由实际渲染函数输出的 DSL 生成；字体、SF Symbol 与 SwiftUI 测量仍需真机确认。

## 待真机验收

用户主动扫码并确认首次登录、当前服务端是否支持该账号、参数粘贴、组件画廊加载、桌面及锁屏的原生文字测量、系统刷新和官网点击。网络或账号风控可能与离线模型不同。

十八秒是主动请求预算；当环境提供计时器时还有 Promise 等待上限。官方未承诺计时器或可取消读体，极端挂起仍可能被二十五秒脚本时限终止，不能承诺所有失败都能画出新提示。iOS 何时刷新不由脚本保证。

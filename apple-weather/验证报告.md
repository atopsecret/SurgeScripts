## 核心功能对照

对照运行的是未经修改的 v3.1.0 原发布脚本；测试模拟其 Egern 旧运行环境，使用同一份合成输入和模拟 API。

1. 可用性：返回相同的 11 个数据集。
2. WeatherKit 保留路径：温度、定位及空日/小时预报的二进制输出一致。
3. 彩云天气：当前天气替换后温度、元数据与编码结果一致。
4. 彩云降水：缺失数据补充，85 分钟结果一致。
5. AQI 六种选项：`EU_EAQI`、`None`、`UBA`、`WAQI_InstantCast_US`、`WAQI_InstantCast_CN`、`WAQI_InstantCast_CN_25_DRAFT` 均输出相同字节。

二进制对照覆盖上述第 2 至第 5 组，共 9 组；它不意味着覆盖 Apple 所有未公开字段与数据集组合。

## 错误与范围检查

- 精确 WeatherKit 主机与接口边界；仿冒子域、认证 URL、非标准端口和相邻路径不消费正文。
- HTTP 非成功状态、空响应、未知媒体类型不猜测正文。
- JSON 损坏、未知结构、超大正文、无效 FlatBuffers 根表、参数错误和第三方 API 失败保留已读出的原文。
- 正文消费一次；读取本身失败时不伪造“完整恢复”。
- 成功改写后清除失效长度、压缩与校验头；失败回退保留原头。
- `ctx.http` 请求去重、GET/POST 范围、HTTPS、超时、16 次上限和 304/ETag 行为通过。
- 多个 ctx 并发时，令牌、数据源及结果不串用。
- 存储错误不阻断业务；诊断不保存令牌、用户坐标、完整 URL 或请求头。
- `env_schema` 类型、默认值、ASN/QUIC 条件、唯一 MITM 主机和二进制脚本开关通过静态检查。

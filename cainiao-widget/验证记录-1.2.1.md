## 实现

- 同次缺 `unb` 的非公共 GW 请求，若有实际 `cookie2/sgcookie` 和有效 `x-uid`，只补 `unb`，保留七项白名单原值，不要求 SID，不以 SID 覆盖 `cookie2`，不借用其它请求或旧缓存。
- `request_cookie_candidate` 与 `native_session_candidate` 都须身份 UID 精确匹配 → COUNT → 完整 PDS。完整空列表也是确认；公共时间、token 和 COUNT 单独成功不是连接证明。
- 两种真实 Cookie 来源即使终止也不被 SID-only 降级。弱流量在屏障写入前被拒绝，不能撤销另一账号保存失败留下的屏障。
- 合法 1.1.0／1.2.0 状态保留账号、代次、token、快照及终止记录。旧首次 native `expired` 只纠正显示为接入未确认，不恢复请求或补造失败原因；未知缓存版本不继承证明，但保留隔离屏障。
- 首次认证类失败为 `unsupported`，显示“App 接入未确认”并停止。已完整确认的会话随后失效或接口不兼容，保留旧快照和原时间；账号不匹配仍隔离。
- 同模块“菜鸟连接状态”显示实际保存字段名、固定 phase／stage／failure／ret／HTTP 分类和轮次，不输出凭据、账号摘要、URL、正文、未知错误原文。最长七天，读取和匿名流量不续期，过期不恢复 terminal。
- 短期 token 更新不重验身份；稳定 Cookie 变化重新检查身份与 COUNT、从 PDS 第一页重取。最多三轮和二十页，共用十八秒预算，保留迟到任务及切号守卫。

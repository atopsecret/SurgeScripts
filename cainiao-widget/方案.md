# 菜鸟取件原生小组件方案

## 1.1.0 手机自动连接

用户要求去掉电脑扫码和手动粘贴的默认流程。本次新增原生请求捕获，在手机上打开已登录的淘宝或菜鸟相关网页后复用经过代理的 H5 登录态。旧 Python 助手仅保留为独立开发工具，不再出现在小组件引导和默认安装步骤中。

- 捕获范围只包括 `h5api.m.taobao.com`、`acs.m.taobao.com` 的 HTTPS `/h5/mtop.…/数值版本/` 请求；官方查件页面及其 MTOP SDK 可证明这两个 H5 网关的用途。不给 `/gw/` 原生签名请求套用 H5 Cookie 规则，不扩大到所有淘宝主机。
- 捕获只读请求头，不读取或改写请求/响应正文，不在捕获脚本中发网络请求，不弹出包含凭据的通知，不在日志保存 URL、Cookie 或账号。
- `cookie2` 和网关 token 都可能属于访客。只有带账号标识 `unb` 且带 `cookie2` 或 `sgcookie` 的请求才作为待验证候选；捕获不等于登录成功，必须由后续个人包裹接口成功返回确认可用。
- 新增设备本地自动凭据存储。自动凭据优先，旧 `CAINIAO_COOKIE` 仅作可选手动参数。没有两者时显示“打开淘宝或菜鸟查件以自动连接”，不再要求扫码。
- 身份不同先清旧快照，避免新账号捕获后继续展示旧码；查询写回前复核当前自动账号，尽量减少捕获与组件刷新的并发覆盖。存储无事务，不能承诺绝对跨进程互斥。
- 组件自己的请求增加固定标记，捕获器忽略，避免把自己的后台查询当作新的手机登录。
- 同一登录会话的 token 更新不会反复重置缓存。保留抓取时间、待验证/已连接/需重开页面等无敏感信息状态；匿名请求不会覆盖已捕获的登录态。
- 官方手机查件页为 `https://page.cainiao.com/guoguo/app-myexpress-taobao/`。默认点击和未连接引导改为这个页面。官方 SDK 在淘宝内可能走 WindVane 原生桥，不能承诺每次打开都一定触发可复用 H5 Cookie；未捕获时必须如实提示，不伪造连接成功。
- 自动捕获需要用户在 Egern 安装并信任自己的 CA、启用上述两个主机解密。模块负责声明范围，不直接修改用户客户端配置。说明只保留手机操作，不再强制电脑和二维码依赖。

本次必须补离线测试：真实候选与访客区分、精确域/路径、原生通道拒绝、请求原样放行、自身请求忽略、存储失败、自动凭据优先和旧参数兼容、token 轮换、账号切换与并发写回、捕获后查询成功才确认、过期后引导重新打开页面。保持原有布局与缓存回归，通过后更新原生模块与文档，先完成本地交付；本轮发布另经确认后推送 GitHub。

### 本轮实现约束

- 请求捕获、组件和只读连接诊断引用同一个自包含脚本 URL；请求入口不返回值，原样透传。原生 `Headers.getAll()` 逐条读取 Cookie，拒绝冲突重名，不消费正文。`storage.getJSON/setJSON` 按官方同步 API 使用，减少不必要的异步交错。
- 本机自动凭据、取件快照和不含敏感信息的捕获结果分开保存。自动凭据只保留 `unb`、`cookie2`、`sgcookie`、`munb`、`_m_h5_tk`、`_m_h5_tk_enc`、`_tb_token_`；不保存昵称和无关追踪 Cookie。自动凭据必须有账号标识和会话 Cookie，后续仍以个人接口结果确认是否可用。
- `CONNECTION_MODE` 默认 `auto`：优先自动凭据，未捕获时允许旧手动参数作为备用。`manual` 禁用捕获并只用手动参数；`off` 禁用捕获，下一次组件执行清空本组件登录态与快照。错误的模式不发业务请求。
- 捕获记录有账号摘要、稳定会话摘要、代次和输入摘要。网关 token 更新改变输入摘要，不改变会话代次，也不清同账号快照；账号变化先清旧快照。过期或身份失效后，必须经过新的手机请求捕获才重新尝试。
- 在每次业务请求、写缓存及返回结果前复核自动凭据代次和输入摘要。途中出现新捕获时停止旧任务，不覆盖新凭据、不回显旧账号包裹。同步回读检测静默写入失败；不把失败写入报为捕获成功。
- 已成功写入本轮状态后，也检查快照键的归属；关闭连接或另一任务写入新账号时，旧手动/自动任务不得在之后恢复已清除的快照。存储 API 不可用时只能显示本次实时结果并提示，无法承诺跨进程取消。
- 新账号捕获先在快照键写入带目标账号摘要的隔离屏障并回读，再写候选凭据。候选写入失败时保留屏障，后续刷新不得继续使用旧账号；新账号保存和查询成功后用其正常状态替换屏障。不能只清快照而遗留可恢复查询的旧登录态。
- 手动空参数不得清除已存在的账号屏障；自动模式读取快照/屏障 API 失败则停止个人查询，不能把未知存储当作无屏障。明确的 `off` 退出会同时清自动凭据和屏障。
- 每次刷新另有执行摘要，区别同账号、同 token 的并发刷新；新任务接管后旧任务不得写回更早快照。自动模式每次吸收网关 Cookie 后仍过滤相同凭据白名单，响应里的昵称和追踪 Cookie 不进入本地缓存。
- 本地存储没有公开的事务或跨脚本作用域保证。同 URL 和命名空间是实现方式，不当作真机共享已经验证；多进程竞态及系统仍显示的旧 timeline 无法靠脚本彻底消除，必须列入手机验收。
- 默认安装说明只包含手机：导入模块、信任本人 Egern CA、打开官方手机查件页并登录、回到组件刷新。淘宝原生桥未触发 H5 时保持未捕获提示，不承诺打开淘宝首页就一定连接。独立 Python 助手仍保留为开发工具，不进入默认引导。
- `setup` 可附短标题 `setupTitle`，区分未连接、关闭连接、手动参数缺失及本机存储异常；关闭连接时不继续要求用户打开查件页。
- 只读连接诊断也读取账号隔离屏障；旧登录态被阻断时优先显示阻断原因，不继续把先前查询成功当作当前账号已连接。

## 目标

在 Egern 原生小组件中清楚显示待取数量、取件码、驿站、快递公司和运单尾号。桌面采用蓝色强调与自适应浅深色背景，取件码优先；锁屏默认隐藏取件码，避免公开个人取件凭据。独立于菜鸟去广告模块，不改写物流业务响应。

## 数据与登录

- 使用公开源码可核实的淘宝 H5 MTOP 账号接口，不用短信读取或未文档化的 Egern 能力。
- 个人包裹接口为 `mtop.cainiao.lpc.packageservice.queryPdsPackageDataList`，固定 `appKey=12574478`，签名为 token、毫秒时间戳、appKey 与原始紧凑 JSON 的 MD5。
- 固定请求域名为 `h5api.m.taobao.com`，只接收该请求的 Cookie 更新；不自动跟随业务响应跳转，不把凭据发往第三方。
- 首次接入优先手机官方查件页和本机请求捕获；无需电脑扫码或粘贴。独立 Python 助手仅作为已有手动流程及协议开发工具，不进入默认安装说明。
- 自动模式优先使用本机捕获凭据，未捕获时允许 `CAINIAO_COOKIE` 手动备用；网关 Cookie 更新保存在设备本地。参数不是加密保险箱，导出配置可能包含凭据，说明文档明确标识。
- 旧独立登录助手仅允许 HTTPS 的淘宝、天猫、菜鸟登录域族，Cookie 遵从域和路径，逐跳校验重定向，限时、限跳；登录收尾后必须检查账号接口成功才输出凭据。

## 状态与缓存

- 有效真实取件码优先判待取；过滤 `NEEDSMS`、`0`、`-1`、`null` 等哨兵，保留需验证说明，不把驿站代收当本人已领。
- 分页有总时限和页数上限。全部查询成功才更新完整快照；部分成功保留历史并标明数据未取全，不冒充准确总数。
- 未登录、登录过期、风控验证、网络失败、未知结构均有独立提示。失败保留上次快照和原更新时间，不显示为零件。
- Cookie 导入内容变化时优先采用新凭据；以账号身份摘要隔离缓存，缺少可靠账号标识时以会话摘要隔离。更换账号不会展示旧账号包裹。
- 仅缓存展示必需字段，不记录完整响应、地址、姓名或完整运单号，不写入日志。
- 默认建议十五分钟后刷新，服从 iOS 调度；不承诺实时、不提供虚构的点击复制或领取按钮。

## 显示合同

渲染入口为 `renderWidget(model, family, now)`。模型字段为 `status`、`items`、`total`、`updatedAt`、`message`、`privacy`、`refreshMinutes`，可选 `partial`。条目字段为 `id`、`code`、`station`、`company`、`tail`、`requiresVerification`。

- `status`：`ready`、`setup`、`expired`、`offline`、`verify`、`partial`、`error`。
- `total` 是当前可确认待取条目数；`partial` 时数量标为“至少”，不能展示为完整数量。
- 小尺寸突出第一件，中尺寸显示两件，大尺寸显示四件，超大尺寸显示更多；超过可视范围明确显示剩余数量。
- 空列表、缺码、长站名、超长码与多件均要布局检查。锁屏三种尺寸显示数量/状态，只有显式打开隐私选项后才显示码。
- 点击使用已核实的官方菜鸟 HTTPS 网页，不猜测 App scheme；没有经过验证的详情链接时不伪造详情页。
- 使用官方文档 DSL 字段，原生与离线预览共享同一棵 DSL。预览使用合成数据并标明“离线预览”，不当作真机截图。

## 文件与构建

- `core.mjs`：签名、数据规范化、状态判定。
- `auth.mjs`：请求头捕获、本机候选与连接状态、隔离屏障和只读诊断。
- `render.mjs`：七种组件尺寸的原生 DSL。
- `runtime.mjs`：Egern 网络、存储和容错。
- `build.mjs`：构建自包含 `cainiao-widget.egern.js`，支持 `--check`。
- `cainiao-widget.egern.yaml`：请求捕获、通用脚本、小组件、只读诊断、两个精确 MITM 主机和无个人值的参数定义。
- `login.py`：独立本地扫码助手；依赖仅限二维码编码库，协议处理使用标准库。
- `tests/`：离线网络/缓存/渲染/登录边界测试，全部使用合成数据，不执行真实登录。

聚焦验证签名向量、Cookie 更新、登录重试、分页/时限、哨兵码、代收、账号隔离、失败保留、隐私以及 DSL 合同。扩展仓库校验器以检查 widgets 与 generic 脚本关联。各尺寸生成离线预览并目视检查，再运行全仓回归。本地交付先检查无凭据与文件哈希；GitHub 发布需本轮另行确认。最终保留真机首次登录、接口可用性和 iOS 原生排版待验收项。

## 实现复核补充

- 手动导入值未含 `unb` 时也跟踪服务器后续补出的账号；已知账号变化或被删除后立即清空快照，并停止复用同一导入值，等待新手机捕获或手动导入。
- 待取件缺少运单号和包裹主键时停止更新，不能依靠站名与缺码证明两条记录重复。
- HTTP 和读体前后均复核预算；检测到计时器能力时另有限时等待。官方没有承诺计时器或可取消读体，缺少计时器时极端挂起依赖原生 HTTP 与二十五秒脚本时限，不能保证画出新的错误提示。
- 最终离线布局覆盖六十像素圆形锁屏、二百九十二乘一百四十一像素中号和长文本；预览是同源 DSL 的近似渲染，原生文字测量仍由真机验收。

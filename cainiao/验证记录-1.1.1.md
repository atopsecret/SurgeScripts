## 抓包结论

第二份样本为菜鸟 `8.11.1105`，Surge iOS `5.23.0` 导出，时间范围 `20:03:06–20:03:12`，共 156 条请求。

日志中有 83 条请求明确命中“菜鸟去广告”并拒绝，包括 SSP 两次、UC 曝光九次、广告监测八次。旧模块已经生效。

另有同一张广告图片四次成功返回 HTTP `200`，每次 78,044 字节，三种菜鸟 UA 均出现。已提取并本地查看图片，底部包含广告创意及活动商品说明。请求日志显示这些图片经 `Domestic.list` 放行。

`1.1.0` 图片条件写死了单个素材 ID 和 `/tos-cn-p-0051-ce/` 目录。第二次素材同时更换 ID 和目录，使用 `/tos-cn-p-0051/`，因此没有命中。抓包能够证实此次网络漏拦；不能单凭这份记录判定 App 是否还缓存了其它素材。

## 修复范围

将单张图片对象条件改为目录和格式条件，同时要求菜鸟 UA：

```text
HTTPS + p3-sign.douyinpic.com
目录：/tos-cn-p-0051/ 或 /tos-cn-p-0051-ce/
文件：字母、数字、下划线或连字符组成的 ID + ~tplv-noop.image
UA：Cainiao4iPhone/* 或包含 com.cainiao.cnwireless
```

两种目录中符合该格式的后续轮换 ID 均能匹配。其它 App 的 UA、普通路径、其它格式、相似主机和额外目录后缀保留。没有扩大到整个 `douyinpic.com`，也没有新增解密主机。规则按 URL 与 UA 判断；菜鸟内符合相同目录和格式的非广告图片也会被拒绝。

17 条原生拒绝条件、四类 Map Local、三组页面清理保持原有结构。Surge 从 Egern YAML 重新构建；双端脚本、模块描述、脚本 URL 及版本头同步更新。

## 更新与验收

手动更新整个模块，确认 Surge 显示 `1.1.1` 或 Egern 显示 `eg-native-20261108-1.1.1`；只刷新远程脚本不会更新图片规则。保持 `p3-sign.douyinpic.com` 在 MITM 范围内，完全退出后重新打开菜鸟，检查新素材请求是否命中“菜鸟去广告”并拒绝。

旧素材已经下载到 App 时仍可能显示；模块不能删除 App 缓存。更新后的手机开屏效果尚未验证。

# 菜鸟取件小组件 1.3.4 手机接入

**1.3.4 正在发布。手机实际连接尚未验收。** 本版只在原“菜鸟连接状态”显示已保存 RPC 的记录时间和十个字段类型，不新增采集、不放松查询合同，也不承诺更新后就能接通。

1. 更新原“菜鸟取件 · 原生小组件”远程模块及其 JS，确认模块描述、generic 和查询 hook 的 JS 首行均显示 **1.3.4**。保持 `CONNECTION_MODE=auto`，手动 Cookie 留空，不重复添加同名模块。
2. 先运行原模块的**“菜鸟连接状态”**，查看已保存的形状时间，以及 appName、source、channel、brand、installStatus、version、ext、token、timestamp、lbs 十项类型。这里只显示固定类型，不显示字段值；记录时间不是原请求 timestamp。
3. 保留已有**菜鸟 App 自带的小组件**，等它下一次实际查询。没有官方组件时才添加一个，正常打开本人菜鸟 App 一次。再看形状时间是否更新，不把出现新 POST 当作形状已经更新的证明；不用删除重装、退出重登、导 HAR 或复制凭据。
4. 在 Egern 小组件画廊运行**“菜鸟取件”**。只有实际 token 和模板被接受，主组件才发新时间戳的独立 POST。首次摘要成功后关闭菜鸟 App，再运行一次；第二次新查询成功才确认关闭 App 后可独立查询。

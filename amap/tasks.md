# 高德模块完整重写

## 目标

依据 2026-11-04 HAR 重写 Surge 模块，核心开屏处理不依赖远程第三方脚本。保留已有首页、搜索、附近、个人页面和打车推广处理的入口，用可读实现替代混淆脚本。只离线验证，不重放抓包、不输出定位与账号、不改运行中的客户端。

## 已确认的抓包事实

- 实际开屏路径是 `/ws/aos/alimama/splash_screen_rt`，旧模块的结尾边界漏掉 `_rt`。
- 该请求返回 200、multipart/form-data，共 210971 字节；`jsonData` 内含一条 `data.custom_list` 广告，另有 PNG 和 JPEG 两个二进制部分。
- 26 次 `optimus-ads.amap.com` 素材请求已被现有规则集拒绝；仅屏蔽素材 CDN 不足以覆盖内嵌素材。
- 抓包期间启用了全域捕获解密，不能据此证明平时模块自己的证书与解密范围已生效。

## 实现约定

- 使用 Map Local 在联网前返回空广告响应，RT 保持 multipart/jsonData 结构、成功状态及空 custom_list，不返回图片部分；旧 aos 和 valueadded 通道返回空广告 JSON。
- 原安装 URL 保持不变，但模块内容重新编写；新增自托管页面脚本，不再引用混淆脚本或第三方 CDN。
- 请求匹配锚定 AMap 主机与已知路径边界，覆盖 `_rt`，不匹配伪造域名及未识别后缀。
- 页面处理只改已知字段和明确广告标记，保留导航、定位、未知卡片、响应业务状态与服务端错误。
- 改写后更新内容类型并去掉过时长度、编码与校验头；未知格式、错误响应和无变化响应原样放行。
- 提供版本日志和无凭据的本地计数诊断。Map Local 命中通过请求记录与版本响应头验证，不伪称有脚本统计。
- 不要求删除 App、关闭自动更新、全域封锁阿里调度或全域图片 CDN。已有缓存是否继续展示需要真机验证。

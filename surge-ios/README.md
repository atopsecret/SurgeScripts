# Surge iOS 功能适配

这份目录保存已从 Egern 现用功能迁移的 Surge iOS 版本。脚本通过本仓库远程加载，不需要在手机的配置目录维护一批本地 JavaScript 文件。

## 范围

- 保留 11 项功能：扫描全能王、菜鸟去广告、Apple 天气、YouTube 增强、高德、京东、闲鱼、拼多多、红果、戒烟军团和蔚来。
- 14 份独立脚本，其中 13 份供默认的 28 个执行入口复用；京东 POST 关联脚本是默认禁用的可选项。
- 不包含电信、移动、VPS、菜鸟取件等纯展示组件。
- 不发布个人代理节点、订阅链接、客户端 Token、Cookie、证书或私钥。
- 不覆盖仓库原有 Egern 版本。这个目录是 Surge 运行环境的独立适配，不是把 `.egern.js` 改一个扩展名。

## 模块安装

模块位于 `modules/`，脚本位于 `scripts/`。模块的 `script-path` 直接引用本仓库对应脚本。

在 Surge 中安装所需 `.sgmodule`，确认脚本与重写开启。HTTPS 功能需要信任当前客户端自己的 CA。同一个功能只保留一套入口：已有主配置内联功能时，不要再重复启用同功能模块。

手机主配置可以将脚本固定到本次发布提交，以避免其它更新改变已经验收的版本；手动更新到后续提交即可升级。独立模块的日常安装入口使用 `main`。

## 行为保持

- 菜鸟、高德、京东、闲鱼和拼多多保留现用精确接口与错误回退；不扩大未知业务范围。
- 红果保留 78 条规则，不包含会破坏主配置加密 DNS 的公共 DNS 拒绝项。
- 京东 POST 关联默认禁用；该备用脚本不会因为下载就自动执行。
- 天气保持 WeatherKit 3.1.0、FlatBuffers 24.12.23，二进制输入输出不转成 JSON 文本。
- YouTube 使用请求/响应两个 dispatcher 覆盖 9 个入口，包括后台/PiP、画质、字幕及原生下载功能；保持局部 QUIC 规则。
- 蔚来保持 3.2.0 四入口：捕获、响应统计观察、每天 09:00、手动诊断。它只使用当前 Surge 客户端新存储键，首次需捕获自己的 App 请求，不复制 Egern 登录存储。
- 扫描全能王只定点修改原字段，保留未知 JSON 字节与大整数。

## 功能数据请求

天气替换会向选择的数据源发送天气查询坐标；双语字幕会向翻译服务发送当前字幕文本。蔚来凭据只由当前客户端保存，并发送到原蔚来服务接口，不写入公开脚本。手动诊断不额外请求账户数据。

## 手机正文缓冲

YouTube 真正改正文的请求保留 `requires-body=true` 和二进制模式，上限 1 MiB；核心/UMP 响应上限 4 MiB、下载动作 1 MiB、字幕 2 MiB。

Surge 对响应超限会跳过该次脚本、保留原响应；对请求超限则在脚本前终止连接。HTTP 缓冲大小不等于整个 JavaScript 执行内存。复杂二进制脚本使用 WebView，轻量捕获使用 JSC。

## 版本与验证

本次迁移只更换部署和引用位置，不调整现用功能参数或规则语义。离线测试覆盖 JSON、SOAP、FlatBuffers、protobuf、UMP、字幕、NIO 状态机和模块映射，全部网络、存储与通知使用本地模拟。

```sh
# Node.js 24 或以上
node --check surge-ios/scripts/nio-auto-checkin-ios.js
# 274 项原功能回归 + 12 项发布完整性检查
node surge-ios/tests/run.mjs
```

离线测试验证转换和回退行为，不等同于在手机上实际完成签到、播放或去广告。功能仍以目标 App 接口返回与手机实际命中为准。

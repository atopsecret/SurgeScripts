## 复现命令

环境：Node.js 26.5.0、Python 3.14.3、PyYAML 6.0.3；不需要 npm 安装。

```sh
python3 amap/build.py --check
node --check amap/amap-cleaner.js
node --input-type=module --check < amap/amap-cleaner.egern.js
node --input-type=module --check < amap/amap-policy.js
node --experimental-vm-modules --test amap/tests/*.test.cjs
python3 egern/validate.py
python3 -m unittest discover -s egern -p test_validate.py -v
git diff --check
```

全仓 Node 命令见仓库首页“离线校验”。所有测试只使用公开源码与合成数据，不访问高德业务接口、不发送定位、账号或请求凭据。

## 来源与边界
